# Exercise-Data-Mining-Heart-Disease-Data-Classification

In this evaluation, classification models such as decision trees and Bayesian methods are assessed to determine the best model for predicting heart disease. The best-performing model is then used to determine whether an individual with given characteristics suffers from heart disease.
This dataset comprises five quantitative features: age, trestbps, chol, thalach, and oldpeak. There are also nine other features—categorical in nature—including sex, cp, fbs, restecg, exang, slope, ca, thal, and num. Among these, 'ca' is treated as a categorical feature because it consists of only four unique values.
Additionally, the 'num' variable serves as the class label column, where a value of zero indicates the presence of heart disease and a value of one indicates its absence.
